# PII Redaction Tool

A Python-based document redaction tool that detects and redacts personally identifiable information (PII) from DOCX documents.

## Features

- Email redaction
- Phone number redaction
- IP address redaction
- SSN redaction
- Paragraph processing
- Table processing
- Header and footer processing
- Automated redaction verification
